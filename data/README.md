Put your Excel file here as:

birthdays.xlsx

Expected worksheet name:

Birthdays

Expected columns:

| Name | Birthday | SlackUserId |
|------|----------|-------------|
| Amit | 1995-09-02 | U0123456789 |
| Rahul | 1997-12-15 | U0987654321 |

Birthday can contain a full date such as 1995-09-02. The script compares only month and day, so the birth year does not matter.

SlackUserId is optional. If present, the workflow mentions the person directly in Slack.
